# Shivam Portfolio

A professional React + Vite portfolio with Home, About, Skills, Projects, and Contact sections.

## Run in VS Code

1. Install Node.js 18+ and pnpm.
2. Open this folder in VS Code.
3. Run `pnpm install`.
4. Run `pnpm dev`.
5. Open the local URL shown in the terminal.

The contact form opens WhatsApp with a pre-filled message for +91 7404966210.
